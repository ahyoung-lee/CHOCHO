직접 등록한 업체 목록

직접 등록은 전화·현장 확인을 뜻하지 않습니다. 영업시간·요금·입장 조건은 방문 전 업체에 확인해 주세요. 엑셀을 저장한 뒤 목록 반영을 요청하면 업데이트합니다.

업종과 조건 필터

여러 업종을 선택한 업체는 각 업종에서 검색됩니다. 조건은 주차가능, 실내 동반, 테라스 동반, 호텔링, 유치원, 애견미용, 저장한 곳 순서입니다. 여러 조건을 켜면 모두 만족하는 업체만 표시합니다. 미확인 항목은 가능으로 표시하지 않습니다.

주변 업체와 지도 위치

주소·장소를 검색하거나 내 위치를 적용하면 기준 위치 주변 10km 이내의 주소 좌표가 확인된 등록 업체만 가까운 순으로 표시합니다. 주변 검색을 적용하지 않은 상태에서는 좌표 미확인 업체도 목록에서 검색할 수 있습니다. 좌표를 확인하지 못한 업체는 지도 핀을 만들지 않으며, 네이버 지도 주소 검색 링크로 위치를 확인할 수 있습니다. 기존 좌표는 도로명·건물번호가 일치할 때만 유지합니다.

저장한 곳과 개인정보

저장한 곳 버튼은 조건 필터의 마지막에 항상 표시됩니다. 하트로 저장한 업체는 현재 브라우저에만 보관됩니다. 새 명단에 없는 업체의 저장 항목은 표시하지 않습니다. 외부 지도 배경과 주소 검색을 사용하면 해당 지도 제공자에게 접속 정보나 검색어가 전달됩니다. 이 사이트는 출발지나 현재 위치를 영구 저장하지 않습니다.
