# 업체정보 입력 파일

`업체정보_입력양식.xlsx`의 `작성안내` 시트를 읽고, `업체정보` 시트에 업체 한 곳당 한 줄씩 작성해 주세요.

- 상호명, 도로명주소, 해당 카테고리 1개 이상을 입력합니다.
- 여러 카테고리에 해당하면 각 항목에 `예`를 선택합니다.
- 주차·실내 동반·테라스 동반 여부는 `가능`, `불가`, `미확인` 중 선택합니다.
- 작성한 파일은 이 폴더에 저장하고, 업체 추가·수정 시 기존 행을 확인해 중복을 피합니다.
- 열 제목과 시트 이름은 유지해 주세요.

현재는 파일을 저장하거나 GitHub에 푸시해도 업체 목록에 자동 반영되지 않습니다. 작성 완료 후 업데이트를 요청해 주세요. 엑셀 불러오기와 동반 펜션 카테고리 연결은 추후 구현할 예정입니다.
