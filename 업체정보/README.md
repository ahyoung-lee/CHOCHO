# 업체정보 입력 파일

`업체정보_간편입력.xlsx`의 `업체정보` 시트에 업체 한 곳당 한 줄씩 작성해 주세요.

- 상호명, 주소, 해당 카테고리 1개 이상을 입력합니다.
- 여러 카테고리에 해당하면 각 항목에 `1`을 입력합니다. 아니오는 `0`입니다. 입력 후 Tab으로 다음 칸으로 이동합니다.
- 주차·실내 동반·테라스 동반·호텔링·유치원·애견미용은 가능 `1`, 불가 `0`, 미확인은 빈칸으로 둡니다. 기존 예/아니오·가능/불가·미확인 입력도 읽을 수 있습니다.
- 작성한 파일은 이 폴더에 저장하고, 업체 추가·수정 시 기존 행을 확인해 중복을 피합니다.
- 열 제목과 시트 이름은 유지해 주세요.

파일 저장만으로 사이트에 자동 반영되지 않습니다. 작성 완료 후 업데이트를 요청해 주세요. 반영할 때는 이 엑셀에 있는 업체만 남기며, 엑셀에서 삭제한 업체는 사이트 목록에서도 빠집니다.

직접 반영하려면 저장 후 프로젝트 폴더에서 `python scripts/import-workbook.py`를 실행하고, 데이터 검증·빌드·테스트 후 배포합니다. 상호명과 주소가 모두 있어야 반영됩니다.
